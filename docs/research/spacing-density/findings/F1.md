## Conflicting evidence
- Data rows M1 48dp vs M2 52dp = version change, do not mix. M1 last-row 56dp vs M2 header 56dp is coincidence.
- List one-line M1 48dp (56dp w/ avatar) vs M2/M3 56dp = generation change; dense M1 40dp persists as desktop-dense value.
- Authorship: spec.fm 8-Point Grid is Bryn Jackson, not Elliott Dahl; Dahl wrote designsystems.com guide. Blogs conflate them = one derivative cluster; both primaries read here.
- Cards: M3 defines no universal inset (Compose Card adds no auto-padding; samples add .padding(16.dp) in content) vs M1 16dp prescription — M1 number is a baseline, not an M3 mandate.
- Touch 48x48dp stable M1-M3; WCAG 24px minimum cited in blogs is a different standard, not Material canon.

## Gaps
- No dedicated M3 data-tables page (M3 ships no data-table component as of fetch); M2 52/56dp is canonical fallback, marked secondary.
- List 56/72/88dp unverified in fetched primary bodies (M3 specs JS canvas; Android List.md omits dp), marked secondary.
- M2 responsive-layout-grid exact breakpoint/margin table unverified raw (JS-blocked); cited via M1 responsive-ui primary + search snippet secondary.
- Dense data-table variant: no official dense row height found (only dense lists 40dp, dense fields 54/48dp, dense menu 32dp secondary) — genuine gap, no number given.
- M3 publishes no single global spacing-token scale; adaptive breakpoints + per-component specs replace it — no quotable "M3 spacing scale".

## Summary (caveman)
- Canon 8pt grid, 4pt half-step, 4dp type baseline. Jackson spec.fm + Dahl guide + M2 spacing-methods agree.
- Touch floor 48x48dp, gap >=8dp. Stable M1-M3. Icon 24, avatar 40 sit inside 48 target.
- Cards: 16dp text pad; top 16/24, bottom 16/24; actions 8dp; gutters 8/16/24/40; mobile card gap 8dp.
- Lists M3: side pads 16 left / 24 right, icon top 8 (12 if tall); M1 rows 48 (dense 40), avatar 56; 56/72/88 secondary.
- Tables: M1 row 48, M2 row 52 + header 56, col gap >=56; dense table number absent.
- Inputs: 56dp default (24+10 fill, 17+17 outline, sides 16, stroke 1/2); dense 54 fill / 48 outline.
- M3 layout: breakpoints <600 / 600-839 / 840-1199 / 1200-1599 / 1600+; no global spacing scale.
